# GEMINI.md

## Project Overview
This project provides a suite of Zsh/Bash scripts designed for automated video conversion from `.mov` to `.mp4` format, specifically tailored for the LSC environment. The core workflow involves scanning directories for MOV files, converting them using FFmpeg (with macOS hardware acceleration support), and managing the lifecycle of original files by renaming and eventually deleting them.

### Main Technologies
- **Shell Scripting:** Zsh/Bash for automation.
- **FFmpeg:** Used for high-quality video encoding.
- **Hardware Acceleration:** Utilizes `h264_videotoolbox` for efficient encoding on Apple hardware.

---

## Directory Overview
The directory contains the conversion scripts and utility scripts for cleanup.

### Key Files
- **`MOVtoMP4_convert.sh`**: The primary conversion script. It recursively finds `.mov` files, converts them to `.mp4`, outputs progress to both the terminal and log files, and uniquely renames the original files to `.mov.original`.
- **`generate_list_to_delete.sh`**: Scans a target directory (typically on a NAS) for `.original` files and populates `toDelete.txt`.
- **`deleteOriginals.sh`**: Reads `toDelete.txt` and permanently deletes the listed files.
- **`commands.md`**: A reference file containing useful one-liners for managing the media archive.
- **`toDelete.txt`**: A temporary list generated by `generate_list_to_delete.sh` for use by `deleteOriginals.sh`.

---

## Usage

### Conversion Workflow
1.  **Navigate** to the folder containing the MOV files you want to convert.
2.  **Run the script** from its installed location:
    ```bash
    /path/to/MOVtoMP4_convert.sh
    ```
    *Note: The script renames originals to `.mov.original` to prevent redundant conversions.*

### Cleanup Workflow
1.  **Generate deletion list**:
    Navigate to the archive/NAS directory and run:
    ```bash
    path/to/generate_list_to_delete.sh
    ```
2.  **Verify `toDelete.txt`**: Ensure the list contains the files you intend to delete.
3.  **Execute deletion**:
    ```bash
    ./deleteOriginals.sh
    ```

## Development Conventions & Notes
- **Paths**: The conversion script operates dynamically and can run from any location without hardcoded paths. (Note: other utility scripts may still contain hardcoded paths requiring manual updates).
- **Environment**: Optimized for macOS using hardware acceleration (`h264_videotoolbox`). The system requires `ffmpeg` to be installed system-wide via Homebrew; the script checks for this automatically.
- **Logging**: The script outputs progress directly to the terminal while simultaneously writing logs into a `logs/` folder created in the directory where the script is run.
- **Permissions**: When working with network shares (NAS), ensure the execution user has sufficient read/write/delete permissions.
